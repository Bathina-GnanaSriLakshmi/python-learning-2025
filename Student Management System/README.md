Overview

A modular, console-based Student Management System built using Python and Object-Oriented Programming principles.
The system supports secure admin authentication, file-based data persistence, and complete CRUD operations.

Features

🔐 Admin login with password
➕ Add new student records
🔍 Search student by roll number
✏ Update student details
❌ Delete student records
📊 Sort students by marks
💾 Persistent storage using file handling
🏗 Modular project structure

Tech Stack

Python
OOP (Classes, Methods, Encapsulation)
File Handling
